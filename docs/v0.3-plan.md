# v0.3.0 implementation contract

Approved on 2026-10-28. Stable baseline: v0.2.2.

1. Model-derived state/transition/W/Wp regression suites, versioned expected outputs,
   complete versus truncated generation, native execution and JUnit output.
2. Prefix sharing with a checkable mapping for every original assertion. Fresh
   stability probes remain independent. Deterministic, resettable Mealy semantics
   are required; model coverage is not implementation code coverage.
3. Finite input/output safety monitors: forbidden event, after-event prohibition,
   and prohibition until a successful release event. Model predictions require
   fresh target replay before they become confirmed findings.
4. Bounded product-graph diagnosis of multiple differing contexts, each separately
   replayed against both actual components. Contexts are not independent bug counts.
5. Self-contained offline HTML evidence viewer with escaped target labels.
6. Reproducible experiments: 60 new minimal/reachable targets up to 64 states,
   >=1000 behaviorally inequivalent controlled mutants, preservation of every
   assertion, and identical compact/uncompressed detection results. Cost goals
   (30% median fewer resets; 50% for prefix families) are hypotheses until measured.

Release gates: existing source and real-component checks, all four backends,
cross-platform CI, exact-version public consumer checks after publication, explicit
limitations, Apache-2.0 notices, no invented measurements. Preserve old releases.
Freeze target: October 30; October 31 is reserved for acceptance and recovery.
