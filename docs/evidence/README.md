# Reproducible evidence

`query-study.json` is generated by the native CLI benchmark. It records physical reset/step calls, logical queries and cache hits; it contains no timing claims. Active costs include inference and W-method conformance. The exhaustive reference receives the final model, so it does less conceptual work; the report is not a generic learner speedup comparison.

`fixtures/session.json` is exported from the learned controlled session adapter. `fixtures/session-buggy.json` is an intentionally defective complete model authored for the regression example. Neither fixture is a third-party vulnerability claim.
