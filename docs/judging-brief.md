# MoonStateLens 季度展示提纲

## 一页项目说明

目标用户是维护有状态 MoonBit 组件、协议适配器和 CI 回归门禁的开发者。
提供有限 reset/step 接口后，MoonStateLens 根据实际实验推导可观察状态，
无需用户先手写完整参考模型。核心由 MoonBit 实现：L* 观察表、KV 区分树、
反例分解、条件式 W/Wp 验证、行为规则及真实差异确认。

v0.4 的新增贡献是历史模型引导重新学习和二分 KV 反例处理，补充真实
MoonLimit 配额/限流案例、AALpy 独立对照，以及可本地运行的实际编译程序演示。
历史模型提供实验结构，新版输出全部重新观察。它不是原程序代码自动修复器。
公开语料和条件明确区分理论前提、合成实验及真实组件执行。

## 三分钟演示

1. 0:00–0:30：说明“组件升级可能改变历史相关行为”，打开浏览器实验室。
2. 0:30–1:15：运行实际 MoonBit 程序，展示旧版三状态、新版四状态模型。
3. 1:15–1:50：展示冷启动 83 次、历史引导 54 次实际重置；三次 acquire
   的新鲜回放在最后一步出现拒绝/允许差异。说明容量变更是受控案例。
4. 1:50–2:20：切换令牌桶和 LRU 模型，下载 JSON/JUnit。
5. 2:20–3:00：打开验证记录，展示四后端、独立参考、原始数据和限制。

## 常见问题

- 独立核心是什么？从观察构造状态等价类、主动选择区分实验并修正假设，
  不是只比较用户已经提供的两个状态图。可查看 learning_table/tree/seed.mbt。
- 历史模型错误怎么办？重新采集新版观察；表闭合、一致修复及正常验证继续运行。
  不匹配的字母表/抽象被拒绝，预算不足为未完成。
- 是否保证任意程序等价？不保证。有限、确定、完全输入及可靠重置是前提，
  W/Wp 还需要正确的状态上界；观察模型不是任意程序内部全部状态。
- 61% 是否普遍成立？仅指公开固定 20 对模型的物理重置中位数，包含验证。
  原始数据保留，其他结构可能零收益或退化。
- 是否发现上游漏洞？目前展示的是实际第三方组件的受控配置变化/适配层变异，
  不声称发现未经确认的上游漏洞，也不把自建消费者称为第三方采用。
- 使用 AI 是否影响解释？AI 辅助开发已披露；需要掌握实验结构、验证前提、
  开源来源和失败结果含义。演示以可重现的执行和证据支撑说明。
