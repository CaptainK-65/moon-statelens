# 独立核心与评审案例

## 项目承担的职责

输入是一个有限操作集合和可执行的 reset/step 黑盒，不需要参考状态表；输出是根据实验得到的 Mealy 行为假设、区分实验和可以真实重放的版本差异。核心职责是从可观察行为推导状态划分，而不只是运行已有模型、记录调用日志或渲染状态图。

## 已有依赖组合后仍需实现什么

| 能复用的基础能力 | 本仓库新增的核心 |
| --- | --- |
| 标准库集合、数组、JSON | Mealy 后缀观测表、闭合／一致修复、状态等价类、假设构造 |
| reset/step 回调 | 根据反例选择新的区分信息，重新推导模型 |
| 图遍历基础机制 | 完整模型最短区分词、最小化、反向状态对区分集构造 |
| 测试执行与随机数 | 根据当前假设构造 W-method 实验，管理条件与未完成结论 |
| 序列执行与报告 | 真正回放模型分歧，将未复现分歧反馈为学习实验 |

根包 moon.pkg 只导入标准库。MoonLoom、CBOR、现有状态测试器、LearnLib 和 AALpy 均未作为核心计算依赖。原先 MoonCAR 的归档、索引或分帧实现没有被复用为本项目核心。

## 案例一：短观察相同，长后缀才能分离

learning_test.mbt 的七状态目标对 advance 总返回 tick。许多历史在短期观察下相同，只有继续推进并 probe 才能识别差异。工具通过反例增加区分后缀，学习到七个状态；随后由独立完整模型比较验证等价。单纯缓存已经执行过的边或拼接状态测试库不会自动完成这些状态等价类和后缀修正。

## 案例二：新旧会话行为回归

两个受控版本的 login、logout 即时响应相同，但 login/logout/request 后 request 返回 denied 与 allowed。compare 学习双方并实际执行区分序列。另有相同目标、初始模型不同的测试，验证不会把模型近似误差当成真实缺陷。

已有状态测试工具也可能发现这个缺陷。本项目新增的是自动获得模型与实验，而不独占“发现退出错误”的结果。

## 案例三：真实 MoonLarder

现有 LRU 库只作为被测组件，适配器不读取其私有字段、转移表或参考规范。限定容量与操作后，工具通过公开 API 推导十状态模型。独立规范只用于学习结束后的等价验收。这个实例验证学习器可消费真实 MoonBit 生态组件，而不只消费作者编写的表驱动模型。

## 可核对的证据

- observation_table.mbt / learning.mbt：学习核心及查询边界。
- learning_test.mbt / generated_test.mbt：长后缀、200 个生成目标和独立等价检查。
- characterization_test.mbt：反向状态对算法与独立 BFS 交叉核对。
- adapters/moonlarder/lru_test.mbt：真实组件学习与事后独立规范比较。
- compatibility_test.mbt / hardening_test.mbt：真实回放、虚假模型分歧、预算和漂移。
- tools/verify_cli.mbtx：公开命令的端到端复现。

本项目采用已发表算法，不声称全球原创。原创工程贡献、参考来源、实际组件接入和适用条件分别记录，具体赛事审核由主办方判断。
